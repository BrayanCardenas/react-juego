# React Juego

Proyecto desarrollado con **Vite + React**, pensado como práctica de frontend interactivo.  
El objetivo es construir un juego sencillo (ejemplo: Tic Tac Toe) que muestre manejo de estados, componentes y estilos modernos.

---

## Características
- Juego interactivo con lógica implementada en React.
- Uso de **hooks** (`useState`, `useEffect`) para manejar estados.
- Estilos personalizados con CSS modular.
- Configuración con **Vite** para un entorno rápido y ligero.
- Deploy en **Vercel** y soporte para **GitHub Pages**.

---

## Tecnologías utilizadas
- **React**  
- **Vite**  
- **JavaScript**  
- **CSS**
